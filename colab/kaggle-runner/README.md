# runner.ipynb

Обёртка Kaggle-ядра. Шесть ячеек: репозиторий и зависимости → секреты в env →
параметры кэша и рендера → cloudflared → запуск раннера.

Ничего специфичного для KAE здесь нет — логика в `src/agents/runner/`,
блокнот клонирует `main` при каждом запуске (начисто — прежняя копия
удаляется). Менять его нужно только когда меняется само окружение:
зависимости, туннель, порядок запуска.

**Перезапуск после правки раннера:** push в `main` → *Stop session* →
*Run All* → адрес из ячейки 4 прописать агенту в `agents.json` движка.
Ячейка 5 работает, пока жив раннер. Как подключить и проверить, что поднялся
новый код, — в [../README.md](../README.md).

`kernel-metadata.json` — для `kaggle kernels push`. GPU и интернет включены:
интернет нужен и для клонирования репозитория, и для скачивания документов
при запросах по ссылке.

Полное описание — в [../README.md](../README.md).
