# Стенд сборки книги (book bench)

Насколько хорошо книга целиком возвращается из движка: то, что сделал сам
продукт — документ после пайплайна и PDF постраничной сборки, — кладётся на
исходный PDF страница за страницей. Стенд ничего не разбирает и не собирает
сам: обвязка, которая это делала бы, мерила бы себя.

## Как прогнать

Книга идёт обычным путём, через сервис (см. `docs/deploy/testing-the-pipeline.md`):

```bash
# на rpi5
curl -s -X POST http://localhost:8000/api/v1/documents/upload -F 'file=@/home/alex/toc-dev/books/mcs40.pdf'
curl -s http://localhost:8000/api/v1/jobs/<job_id>/progress            # до COMPLETED
curl -s -X POST http://localhost:8000/api/v1/jobs/<job_id>/assemble/preview
curl -s http://localhost:8000/api/v1/jobs/<job_id>/result > result.json
# PDF сборки: /data/kae/<job_id>/preview_pages.pdf
```

```bash
python3 -m benchmark.book.bench --source mcs40.pdf --rebuilt preview_pages.pdf \
    --result result.json --out report_dir
```

Запускать в контейнере `kae` с примонтированными `tests/` и `benchmark/` и
установленным `requirements-dev.txt`: меры наложения берутся из e2e-тестов.

## Что меряется

| мера | что значит |
|---|---|
| **pages** | в какие страницы сборки ушла каждая исходная (по тексту); потерянные и вылезшие на вторую |
| **text** | доля текста страницы, которая есть в сборке (четвёрки букв внутри строк — порядок строк и разбитые слова не мешают) |
| **blocks** | каждый блок текста исходника найден в сборке по словам и наложен как чернила — мера теста абзацев, лимит 10% |
| **figures, tables** | каждый рисунок и таблица документа: область исходника против области сборки, поставленной по ближайшему найденному блоку, — мера теста рисунков |
| **headings** | оглавление самой книги против заголовков документа: записи, на которые есть заголовок; записи, привязанные к странице |

Выход — `report.json`, `report.md` и `sheets/NNNN_<почему>.png`: исходная
страница рядом со сборкой для худших страниц по тексту и по блокам и для каждой
десятой. Число говорит, что страница разошлась, а не что на ней не так —
листы надо смотреть глазами.

## Чего стенд не видит

- Рисунки и таблицы берутся из того, что нашёл продукт: пропущенный рисунок
  мерой не ловится — только на листах.
- Блоки текста берутся из текстового слоя исходника: чего нет в слое (OCR не
  прочёл), того стенд не спросит.
